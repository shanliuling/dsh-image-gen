# 0.8.6 — 设置兼容性检查与加载状态修复

## 修复与改进

- 将 `@deepseek-ai/schemastery` 的兼容范围修正为 `>=3.18.4 <4`，仍接受后续兼容的 3.x 版本。
- 根据插件实际加载的 schema 检测现代 DSH 所需的 volatile 字段。缺少能力时显示明确的更新提示并阻止无效保存，服务端同时记录原因。
- 设置卡区分加载中、远程连接不可保存、设置不可用、配置只读和依赖不兼容，避免统一提示为配置文件只读。
- 修复设置在首次渲染和订阅之间更新时，卡片可能一直保留禁用状态的问题。
- 保留旧 DSH 的设置注册路径，增加 Windows/Linux 的独立安装包验证。

## 更新说明

更新插件后请重启 DSH，并刷新页面。已有安装环境仍需确保插件实际解析到的 `@deepseek-ai/schemastery` 满足 `>=3.18.4 <4`；更新插件和版本声明不会自动替换已有的旧依赖副本。

## 验证与 issue 状态

- 已复现 #71 所述的旧 schema 导致保存失败的条件；独立安装包测试验证 DSH 0.2.0-rc.2 与 schemastery 3.18.4 能保存设置，并在重开表单和重启宿主后保留配置。
- schemastery 3.18.2 场景验证明确的不兼容提示及写入阻止。
- #68 的空白卡片和 #70 的无法点击症状尚未在反馈者环境复现，需要更新后回测，暂不认定为已解决。
- 独立安装包测试覆盖真实 React、设置服务及配置文件持久化；浏览器 DOM、完整桌面壳、RPC 传输和真实图片生成请求不在该测试范围内。

Related: #68, #70, #71.
